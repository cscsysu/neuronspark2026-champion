
# DATA NOTICE

`NS-2026-09` 是本地合成可控网格世界数据集，方向为隐变量世界模型评测。数据不使用外部 benchmark 的原始样本、图片、视频或标签。

公开包包含 train/valid/test 的完整初始地图、坐标锚点、probe 动作序列、probe 过程稀疏局部观测、probe 终局完整观测、sensor-only 后续事件观测、聚合传感器、每个 context 下多个 query 动作序列、train/valid query 标签、公开工具和示例提交。公开包不包含 hidden dynamics profile、hidden test query outcome、评分程序、生成 seed、内部审计材料或官方答案。
