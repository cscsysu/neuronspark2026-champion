
# DATA_NOTICE

This package is locally generated MuJoCo-backed dexterous-hand contact simulation data for `NS-2026-07-r20260525-08-gpu-vision-stages`.

It contains public train/valid/test task descriptors, object-family metadata, environment-context metadata, task-combo/stage metadata, public MuJoCo physics variants, weak public demonstration rollouts, MuJoCo-derived tactile probe traces, compact spatial-grid/tactile-image observations from the dev simulator, a MuJoCo dev simulator with lightweight proxy fallback, a Gymnasium-style dev wrapper, public checker, headless 2D replay renderer, `GETTING_STARTED.md`, official runtime contract files and example `agent.py`.

The public splits are intentionally layered: `train_tasks.jsonl` is the base distribution and is large enough for legal offline model training, `valid_tasks.jsonl` is mild distribution shift, and `test_tasks.jsonl` is a local sanity/debug split only. The r08 public train split contains 6000 tasks; valid and test contain 360 tasks each. The public `demonstrations/weak_train_rollouts.jsonl` file contains weak scripted rollouts from public train tasks; it is not optimal and is not an official solution trace.

It does not contain pre-rendered simulation videos or official replay trajectories. Participants can use the included renderer to create local public-task replays for debugging.

It does not contain official private physics rollouts, hidden procedural seeds, hidden task grammar parameters, hidden capability-tier labels for official feedback, hard-slice labels, hidden scoring states, per-rollout official results, optimal actions, server paths, or any external raw dataset labels. Public `valid_tasks.jsonl` and `test_tasks.jsonl` must not be used as leaderboard ranking feedback. Official ranking must use hidden private rollouts generated inside the judge from private seed/config, withheld capability-tier aggregation, unseen object/environment/physics/stage shifts, visual distractors, resource bottlenecks and multitask combinations. If official artifacts include a replay, it is generated from a separate non-scoring hidden-diagnostic task and is bounded/redacted. Official diagnostic artifacts are short-lived; MP4 video is not guaranteed or treated as a long-term archive.

The primary public simulator uses the official `mujoco` Python package pinned in `requirements-mujoco.txt`. If MuJoCo is unavailable, public tools fall back to the lightweight proxy checker so that format checks remain usable, but official scoring should run with MuJoCo installed. `RUNTIME_ENVIRONMENT.md` and `requirements-runtime.txt` define the r08 leaderboard model runtime contract: Ubuntu 24.04.2 LTS, glibc 2.39, CPython 3.12.3, RTX 4090 D 24GB, NVIDIA driver 580.65.06, `torch==2.11.0+cu128`, PyTorch CUDA runtime 12.8, `mujoco==3.3.7`, `numpy==2.4.6`, `scipy==1.17.1`, `tqdm==4.67.3`, and no network. The historical `aigame-eval-ns202607-mujoco:20260525` image is a CPU/MuJoCo smoke image, not the r08 leaderboard model runtime. See `DATA_PROVENANCE.md` for generation and boundary details.
