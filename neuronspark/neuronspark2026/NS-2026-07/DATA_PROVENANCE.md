## What Is Generated

Public task descriptors are generated from a fixed procedural distribution over task type, object family, object size, mass, friction, compliance, fragility, contact bias, actuator scale, action delay, anisotropic friction, contact stiffness/damping, pose/tactile dropout, compact scene geometry, visual distractors, staged goals, start pose, target pose, tool goal, environment context and resource constraints. The public distribution is split by difficulty: train uses base parameter ranges, public valid uses mild distribution shift, and public test uses a stronger but still public sanity distribution.

Public `demonstrations/weak_train_rollouts.jsonl` contains weak scripted rollouts over public train tasks and public variants. Each episode records compact observations, stage context, tactile heatmaps, teacher actions, final state and rollout metrics. High-dimensional `vision_grid_16x16` and `tactile_image_7x8x8` observations can be regenerated from the public simulator for those same tasks. These rollouts are provided to make imitation learning, offline policy learning and world-model training legitimate public strategies; they are not optimal actions and are not used by the judge as reference answers.

Public `tactile_probes/` are generated by running small scripted perturbations in the public MuJoCo dev simulator when the `mujoco` package is available. Each probe records derived contact/tactile signals such as normal force, shear, vibration proxy, contact coverage and slip precursor. These probes are for offline feature learning only and are not official rollout transcripts.

Hidden judge tasks are generated inside the official judge from a private procedural seed/config and the hidden branch of the task grammar. Hidden rollouts randomize object family, mass, friction, fragility, contact bias, actuator scale, friction anisotropy, contact stiffness/damping, action latency, pose/tactile dropout, compact obstacle/corridor/occlusion scenes, visual distractors, staged goals, noise, start pose, target pose and resource constraints beyond the public train ranges. Static hidden jsonl snapshots may exist in internal release evidence only for regression/fallback; they are not public data and public leaderboard ranking must not use public test scores.

Official diagnostic replay, when enabled, is generated from a separate non-scoring hidden-diagnostic task. It follows the same task-grammar family as the hidden judge distribution but is not included in official score aggregation and is returned only as a bounded redacted debugging artifact.

## External Data

No external raw robotics dataset, real tactile dataset, human demonstration dataset, web image, pretrained model output or private laboratory measurement is used as source data. MuJoCo is used as the physics/sensor simulation engine, not as a source of task labels.

## Reproducibility Boundary

Public files are reproducible from the generator, the version id and the public seeds above. Official scoring is not reproducible from public data alone because hidden procedural seeds/config, private rollouts and withheld aggregation labels are intentionally excluded.

## Simulator Boundary

The public MuJoCo dev simulator is intentionally compact: planar free-body contact manipulation with derived tactile/contact observations, compact obstacle/corridor scene constraints, compact top-down spatial grids and low-cost actuator/sensor perturbations. It is more physically grounded than the earlier formula-only prototype, but it is still not a full real-robot digital twin, not Isaac Sim, and not a guarantee of sim-to-real transfer.

## High-fidelity Hidden Extension Boundary

Isaac Sim or Genesis are not required for public local development and are not bundled in this public package. If a future hidden high-fidelity layer is enabled, it must be a server-side audit/supplement using the same `Agent.reset/act` observation-action contract, with fixed offline assets, pinned image digest, private calibration tasks and separate release evidence. It must not become a dependency for public participants.
