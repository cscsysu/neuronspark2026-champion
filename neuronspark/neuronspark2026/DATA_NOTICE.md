# Data Notice

This derived dataset is built from the public 20 Newsgroups corpus loaded through `sklearn.datasets.fetch_20newsgroups`. UCI lists the Twenty Newsgroups dataset under the Creative Commons Attribution 4.0 International license.

The participant files do not redistribute raw messages. The released tables contain anonymized dense features, weak labels, trusted validation labels and test features generated for NeuronSpark 2026. Original message text, original filenames, original category mapping, vectorizer vocabulary, SVD components and random rotation matrices are not included.

Participants may use the released files only for NeuronSpark 2026 competition work, practice and writeup reproduction. Do not attempt to reverse engineer original messages or recover hidden labels through external search.
